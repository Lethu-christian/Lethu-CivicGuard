# CivicGuard SA 🛡️

CivicGuard SA is a modern, transparent, and secure digital voting platform designed to empower citizens and ensure the integrity of democratic processes.

## 🚀 Live Demo
Experience the platform here: [Lethu CivicGuard](https://lethu-civicguard.vercel.app)

## ✨ Features
- **Secure Voting:** Cryptographically verified voting process to ensure each vote is counted and tamper-proof.
- **Real-time Leaderboard:** Instant visualization of voting results as they are tallied.
- **Admin Dashboard:** Robust management tools for overseeing elections and contestant verification.
- **Mobile Responsive:** Optimized for use on any device, from smartphones to desktops.
- **Contestant Profiles:** Detailed information and galleries for all candidates.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, React Router
- **Deployment:** Vercel
- **Authentication:** Protected Routes and Secure Login

## 📖 How to Use
1. Navigate to the landing page to learn about the current initiatives.
2. Visit the Voting Arena to cast your vote for your preferred candidate.
3. Monitor the live results on the Leaderboard.
4. Admins can log in to manage contestants and election data.
